# Поиск семантически близких слов

Учебный проект по созданию векторных представлений русских слов и поиску слов с близкими значениями по их контексту.

Проект сделан **без ML-фреймворков и сторонних библиотек**: матрицы, векторы, вычисление softmax и обновление весов реализованы на обычном Python.

## Как работает модель

Используется модель **Skip-gram из семейства Word2Vec**. Она берёт центральное слово и учится предсказывать слова рядом с ним. Для каждого слова учитываются два слова слева и два справа.

Для оценки всех слов словаря применяется полная функция softmax. Веса обновляются методом стохастического градиентного спуска: модель обрабатывает пары «центральное слово — слово контекста» и корректирует векторы после каждой пары.

Параметры текущей версии:

- размер вектора слова: 10 чисел;
- окно контекста: 2 слова в каждую сторону;
- шаг обучения: `0.01`;
- число эпох: `100`;
- сохранение весов: каждые 10 эпох.

Близость слов вычисляется по косинусному сходству их векторов.

## Корпус текстов

Модуль `texts/text.py` читает файлы `*.txt` из `texts/books/` по одному, в алфавитном порядке. Ожидается кодировка UTF-8. Слова приводятся к нижнему регистру; для токенов используются буквенные символы.

Словарь собирается отдельным проходом по корпусу. Во время обучения текст читается повторно, а генератор контекстных пар хранит только небольшое окно токенов. Словарь и матрицы эмбеддингов остаются в памяти.

Сейчас в `texts/books/` лежит короткий пример `01.txt`. Чтобы обучаться на книгах, добавьте туда текстовые файлы `.txt`. 

## Запуск

Нужен Python 3.9 или новее. Сторонние пакеты устанавливать не требуется.

Из корня проекта выполните:

```bash
python main.py
```

Обучение записывает матрицы входных и выходных векторов в папку `embeddings/`. Для текущих настроек создаются файлы с эпохами `0`, `10`, …, `90`. Папка создаётся автоматически.

Полная softmax-функция перебирает весь словарь для каждой пары слов, поэтому обучение может быть медленным. Чем больше корпус и словарь, тем больше времени потребуется.

## Поиск похожих слов

После обучения можно вызвать поиск из Python:

```python
from synonyms_finder import find_synonyms

for word, score in find_synonyms("машина", top_n=10):
    print(f"{word}: {score:.3f}")
```

Искомое слово должно встречаться в корпусе; указывайте его в нижнем регистре. Команда `python synonyms_finder.py` запускает пример поиска для слова `машина`. Поиск загружает сохранённую матрицу `embeddings_in_290.txt` и ранжирует остальные слова по косинусному сходству.

## Структура проекта

- `main.py` — обучение Skip-gram и сохранение весов;
- `matrix.py` — матрицы и векторы без NumPy;
- `words.py` — словарь, токенизация и генератор контекстных пар;
- `texts/text.py` — построчное чтение книг;
- `texts/books/` — корпус `.txt`;
- `synonyms_finder.py` — поиск близких слов по косинусному сходству.
