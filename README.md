# Поиск семантически близких слов

Учебный проект по созданию векторных представлений русских слов и поиску слов с близкими значениями по их контексту.

Проект сделан **без ML-фреймворков**: матрицы, векторы, вычисление softmax и обновление весов реализованы на обычном Python. Для русской морфологии используется библиотека `pymorphy3`.

## Как работает модель

Используется модель **Skip-gram из семейства Word2Vec**. Она берёт центральное слово и учится предсказывать слова рядом с ним. Для каждого слова учитываются два слова слева и два справа.

Для оценки всех слов словаря применяется полная функция softmax. Веса обновляются методом стохастического градиентного спуска: модель обрабатывает пары «центральное слово — слово контекста» и корректирует векторы после каждой пары.

Параметры задаются в `.env` и загружаются через единый модуль `env.py`:

- размер вектора слова: `EMBEDDINGS_COUNT` (по умолчанию `10`);
- окно контекста: 2 слова в каждую сторону;
- шаг обучения: `0.01`;
- число эпох: `EPOCH_COUNT` (по умолчанию `100`);
- сохранение весов: после каждой эпохи.

Близость слов вычисляется по косинусному сходству их векторов.

## Корпус текстов

Модуль `texts/text.py` читает файлы `*.txt` из `texts/books/` по одному, в алфавитном порядке. Ожидается кодировка UTF-8. Буквенные токены приводятся к нижнему регистру и начальной форме с помощью `pymorphy3`.

Словарь собирается отдельным проходом по корпусу. Во время обучения текст читается повторно, а генератор контекстных пар хранит только небольшое окно токенов. Словарь и матрицы эмбеддингов остаются в памяти.

В `texts/books/` добавлен исторический очерк `02_otechestvennaya_vojna_1812.txt` объёмом около 3 100 слов. Чтобы расширить корпус, добавьте туда текстовые файлы `.txt`.

## Запуск

Нужен Python 3.9 или новее. Установите библиотеку морфологии и её русский словарь:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Изменяйте параметры запуска в `.env`; файл `.env` не добавляется в Git.

Из корня проекта выполните:

```bash
python main.py
```

Обучение записывает матрицы входных и выходных векторов после каждой эпохи в папку `embeddings/`. При `EPOCH_COUNT=100` создаются файлы с эпохами от `0` до `99`. Папка создаётся автоматически.

В `.env` установите `TRAIN_FROM_SCRATCH=false` и задайте пути к обеим матрицам в `CONTINUE_INPUT_EMBEDDINGS` и `CONTINUE_OUTPUT_EMBEDDINGS`. Число дополнительных эпох берётся из `EPOCH_COUNT`. Продолжение использует текущий словарь и корпус, поэтому размеры матриц должны ему соответствовать. Результат сохраняется с префиксом `CONTINUE_OUTPUT_NAME` (по умолчанию `embeddings_finetuned`). Чтобы искать с помощью продолженной модели, установите `SYNONYM_EMBEDDINGS_NAME` в то же имя, а `SYNONYM_EPOCH` — в нужный номер эпохи.

Полная softmax-функция перебирает весь словарь для каждой пары слов, поэтому обучение может быть медленным. Чем больше корпус и словарь, тем больше времени потребуется.

## Поиск похожих слов

После обучения можно вызвать поиск из Python:

```python
from synonyms_finder import find_synonyms

for word, score in find_synonyms("машина", top_n=10):
    print(f"{word}: {score:.3f}")
```

Запрос автоматически приводится к начальной форме. Фильтр убирает стоп-слова и оставляет кандидатов той же части речи. Команда `python synonyms_finder.py` ищет слово из `SYNONYM_WORD` по матрице с именем `SYNONYM_EMBEDDINGS_NAME` и эпохой `SYNONYM_EPOCH` из `.env`. После перехода на лемматизацию сначала обучите модель заново: старые матрицы эмбеддингов не соответствуют новому словарю.

## Структура проекта

- `main.py` — создание случайных матриц эмбеддингов и запуск обучения;
- `training_manager.py` — обучение с нуля на переданных матрицах и продолжение обучения из файлов;
- `env.py` — загрузка настроек из `.env` через `python-dotenv`; шаблон настроек — `.env.example`;
- `embedding_manager.py` — создание случайных векторов, чтение и запись матриц эмбеддингов;
- `filter_manager.py` — лемматизация, стоп-слова и фильтр частей речи;
- `matrix.py` — матрицы и векторы без NumPy;
- `words.py` — словарь, токенизация и генератор контекстных пар;
- `texts/text.py` — построчное чтение книг;
- `texts/books/` — корпус `.txt`;
- `synonyms_finder.py` — поиск близких слов по косинусному сходству.
